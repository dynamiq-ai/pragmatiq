> pragmatiq is an independent implementation inspired by the PRAGMA paper

Ephemeral RunPod pod (1× A100 80GB PCIe, community), harness
`scripts/validate_gpu.py` at commit `5eb5f7c` via `scripts/runpod_launch.py`:
small model, 20k users, 100 steps, serving concurrency 1/4, Triton container
leg skipped. Wall clock 45 min on-pod; spend ≈ $1.5.

The harness's verdict logic correctly reported the run as failed
(exit-code/report alignment fixed in Bugbot rounds 2–5).

## Findings feeding fixes

1. **Fine-tune at 20k-user scale did not complete one epoch in ~37 min on an
   A100** and produced zero log output (leg subprocess is block-buffered and
   `LoRAFineTuner.fit` logs nothing until the first epoch ends). Root cause
   not yet isolated — follow-up: run legs with `python -u` and per-epoch
   progress prints, then re-measure on the 8×H100 sweep.
2. **GPU utilisation sampling recorded nothing** on a real GPU pod —
   `nvidia-smi -l 1` under a 5 s `subprocess.run` timeout kills every sample
   (fix in flight: single-snapshot invocation).
3. **The launcher lost the SSH output stream** ~6 min into the run and never
   noticed the harness finishing 40 min before its hard cap; artifacts were
   recovered manually over SSH. Watchdog/artifact-pull hardening is in flight
   (pull-before-terminate ordering, pull excludes bulk artifacts, temp+rename).
